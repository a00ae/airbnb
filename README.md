An interactive **Airbnb Clone** web application built as a **Single Page Application (SPA)** using **React 19**, **TypeScript**, and **Vite**. 

The main objective of this project is to provide a fast, real-time search and filtering engine to filter accommodation listings based on multiple criteria without refreshing the page.

## 🌟 Key Features

The primary functionality focuses on precise accommodation filtering and real-time state management:

- 🏙️ **Location Filtering:** Browse listings available in specific cities and geographic locations.
- 💰 **Price Filtering:** Filter listings within a specified price range to suit various budgets.
- ⭐ **Rating Filtering:** Sort and display properties based on review ratings and top-rated options.
- ⚡ **Instant Response:** Real-time updates to the displayed listings as soon as search criteria change.
- 📱 **Responsive UI:** Clean and adaptable interface optimized for all screen sizes.

---

## 🛠️ Tech Stack

- **Core Framework:** React 19
- **Build Tool / Bundler:** Vite 8
- **Language:** TypeScript
- **Styling:** SASS (`sass-embedded`)
- **Icons:** Remix Icons (`@remixicon/react`)
- **Compiler / Optimization:** React Compiler (Babel Plugin)
- **Deployment:** GitHub Pages (`gh-pages`)

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone [https://github.com/a00ae/airbnb.git](https://github.com/a00ae/airbnb.git)
cd airbnb 
```

### 2. Install Dependencies

```bash
    npm install
```

### 3. Run the Development Server

```bash
    npm run start
```
Open your browser and navigate to: `http://localhost:3000/airbnb`

## 📜 Available Scripts
| Script | Description |
